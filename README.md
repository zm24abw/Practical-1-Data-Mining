# Practical 1: Getting Started with Data

6COM2005 Data Mining and Visualisation

## Aims
- Use Git and GitHub to get and save your work.
- Load a dataset into a pandas DataFrame and inspect its objects and attributes.
- Identify attribute types and the class label.
- Ask simple questions of the data with pandas.
- Choose and draw the right chart for a question (bar, histogram, scatter).
- See why we must always plot the data (Anscombe's quartet).

## Files
- `Practical_1_T.ipynb`: the notebook you complete
- `6COM2005_DMV_Practical_1.docx`: the handout with all tasks
- `penguins.csv`: Palmer Penguins, 344 penguins, 8 attributes
- `anscombe.csv`: Anscombe's quartet, 4 small datasets with x and y

## How to start
1. On this page, click **Use this template** → **Create a new repository**. Owner: your own account. Visibility: **Private**. Click **Create repository**.
2. Clone **your new repository** (not this template): `git clone <your repository url>`
3. Open the folder and run `jupyter notebook`.
4. After each part: `git add .`, `git commit -m "..."`, `git push`.
